House rules

These keep every new cover in line with the 57 already on the blog.

Cover title

  • 3 to 7 words, sentence case
  • No year: it dates the image
  • Brand names spelled their way: Smith.ai, Kore.ai

Second line

  • Under 45 characters
  • Taken from the post's own subtitle or first heading
  • No full stop at the end

Style

  • Keep the suggestion unless the post is clearly another type
  • Same kind of post, same style

Never changes

  • Colours, fonts, grain, layout
  • 1600 × 900 WebP under 90 KB
  • File name = the post's URL slug
