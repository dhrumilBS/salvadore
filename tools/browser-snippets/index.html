Browser Snippets

Small scripts you run on a WordPress page or in wp-admin from your browser.

Quickest: bookmarkletDrag a snippet's ⇱ Bookmark button to your bookmarks bar, then click it on any page.
DevTools snippetCopy the code → F12 → Sources → Snippets → New snippet → paste. Run with Ctrl+Enter.
One-offCopy the code and paste it into the DevTools Console on the page.
