How it works

  1. Pick the website at the top: Healthray or Botphonic.
  2. Click Old revisions (or turn on Only posts with old revisions) to see what can be cleaned.
  3. Use Trim to 5 on a post, or Select old on this page, then delete.

The latest 5 revisions of each post are never deleted. The server enforces this too.
